Commande

Le robot est piloté depuis un autre onglet ou un autre PC.
Clavier
Z ↑ Q ←S ↓D →
Maintenir : tiens Z/↑ pour avancer à la vitesse max, S/↓ pour reculer ; lâche = freinage. Tiens Q/← ou D/→ pour braquer ; lâche = roues droites.
Pas à pas : chaque appui change la vitesse de 0,02 m/s ou le braquage de 2°.
Entrée armer/désarmer · X vitesse 0 · C braquage 0 · Espace ARRÊT.
Le robot s'arrête tout seul si la page ne répond plus pendant 0,5 s, si l'onglet est caché ou si la fenêtre perd le focus.
